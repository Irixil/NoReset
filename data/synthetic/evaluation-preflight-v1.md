# 合成整理输入前置集 v1

`evaluation-preflight-v1.json` 是 2026-10-08 依据当前仓库合同独立编写的合成资料，未改编外部病历或复用旧评测期待。包含 18 个合法整理请求、6 个预期拒绝请求；合法请求另带 4 条历史原话，拒绝请求另带 2 条历史资料，共 30 条虚构原始记录。

依据为 `docs/sdlc/spec-contextual-dialogue-v10.md`、`docs/API.md`、`backend/adapter.py`、`backend/safety.py:document_needs_review` 和 `config/event-v0.3.schema.json`。本集覆盖整理适配器输入、完整原话、来源、发生/记录时间与冲突引用；动态对话接口、恢复与浏览器闭环需要各自的专项验证。

每条当前记录显式提供合法 `source_kind`；历史使用 `record_id/raw_text/source_kind/recorded_at/occurred_time` 规范字段。资料来源的 `source_review` 精确绑定本例完整合成文字。`clinician_evidence` 仅模拟调用方来源声明；适配器没有验证临床人员身份。资料核对声明也不代表真实 OCR、原件目视核对或医学审签。所有病例的临床和语义审核仍为 `pending`。

| 输入 | 目的 |
|---|---|
| PF001 | 老人原话、相对时间，不由参考日期补绝对时间 |
| PF002 | 家属观察来源 |
| PF003 | 家属转述医生话语，保留转述和未知药名 |
| PF004 | 照护员测量原话，不作正常或异常结论 |
| PF005 | 手工编写的转写后文字形状，未进行真实 ASR |
| PF006 | 系统记录来源，不冒充老人事实 |
| PF007 | 自称医生而来源未核实，保持 unknown；分类待语义复核 |
| PF008 | 明确提供 clinician_evidence，仍待核且没有身份认证 |
| PF009–010 | 当前资料核对声明、无法辨认值保留 |
| PF011 | 明确提供绝对发生时间，与记录时间分开 |
| PF012 | 相对原话与明确参考时刻，不换算发生日期 |
| PF013–014 | 他人资料日期与当前发生时间分开 |
| PF015 | 同次事件的两条相反原话，互异原始 ID 待核 |
| PF016 | 同次测量的两源数值差异，互异原始 ID 待核 |
| PF017 | 两条同文记录保留各自来源与 ID，不制造冲突 |
| PF018 | 已核对历史资料与当前转述的同次测量差异 |
| PFR001–004 | 当前资料核对声明缺失、旧文字、错误方法或空确认时间 |
| PFR005–006 | 历史资料缺声明或声明绑定旧文字 |

运行 `python -m scripts.evaluate_synthetic_preflight`。该命令只使用明确创建的 `MockProvider`，没有真实供应商入口，不加载 `.env`。`gate_pass` 只表示可执行输入合同和拒绝门槛通过；报告保留每例人工复核项，临床与语义状态始终待审。

Mock 当前仅生成当前记录的完整 claim，复合输入的其他来源仍在输入历史和冲突引用中。`preserve_both_sources` 的自动检查仅检查标记，不能证明真实交接同时展示了双方原话。Mock 同类冲突检测不能判断真正矛盾或重复事件。分类、自然回应、问题价值、相关背景、完整报告、三层风险适当性、真实 ASR/OCR 和真实模型质量仍须专项及人工审核。

本集没有审核过的风险金标准，不证明普通、尽快评估、紧急三层临床行为。旧 `evaluation.json` 仍独立保留，其严格结果不因新增本集而改成通过。
