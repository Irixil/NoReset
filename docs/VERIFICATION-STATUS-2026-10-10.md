# NoReset 当前验证与源码交付范围

2026-10-10。当前产品目标仍是自然健康交流、可纠正和恢复的原话记录、可追溯医生交接及可控长期记忆。源码交付与线上部署分别验收。

| 能力 | 当前证据范围 |
|---|---|
| 长期记忆 | 本机加密、逐项来源/日期/确认与时间状态、重启后新对话、本人/家属和独立浏览器隔离已完成虚构工程验证。 |
| 模型使用记忆 | 有限真实样例支持相关病史召回、2022年更正与旧药撤销记忆、删除后不再重现旧背景；不表示所有病种或操作变体全覆盖。 |
| 更正和就诊交接 | 正常UI第2版原话与来源、医生视图/PDF、加密备份与恢复有实际证据；完整组合旅程后续采用免费模型夹具，未当成全真实模型链。 |
| 真实语音及多轮回复 | 较早版本有真实转写和纠正/单問/结束样例；当前版本仍需要整条正常语音、实际追问回答绑定、更正、来源和恢复的有界真实补验。 |
| 历史与风险边界 | 有时间、确认、来源和危险信息优先的工程回归；相关背景引起合理选择差异的完整真实对照、临床签署规则和专业交接审核仍待完成。 |
| 失败与身份隔离 | 原件先保存、模型失败保留原话、取消/断网、家庭所属人与不同浏览器资料库有工程证据；不宣称公网多用户账号鉴权或跨设备自动同步。 |
| 发布 | 保留用户未提交工作；只交付源码、测试和安全说明。尚未把代表性Memory结果宣布为全部AI通过或线上部署通过。 |

使用 [README中的长期记忆步骤](../README.md#健康背景与加密备份) 体验入口。确认并选择记住的资料才自动带入同一人的新对话；联网发言可能计费。首次测试请使用独立资料库和明确虚构资料。

完整版本启动方式是 Python 3.12 下运行 `python -m scripts.start_dev`。前端默认端口5173，后端API默认18768；必须以实际启动输出及健康检查确认地址，端口文字不表示某台机器此刻服务正在运行。

删除后的新备份保留删除结果；历史备份不会自动被清除。核对记录不等于风险消除，不授权加减停药。尚无临床签署的问诊策略、风险规则和报告，不宣称临床专业效果；所有者体验与必要真实AI路径通过后再核对既有部署和回退条件。
