## 获取和运行

```bash
git clone --branch codex/backend-integration-2026-09-14 https://github.com/Irixil/bing-li-bu-gui-ling.git
cd bing-li-bu-gui-ling
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
cp .env.example .env
```

按 README 在本机 `.env` 填写自己的服务配置，不把密钥提交到仓库。执行 `python -m scripts.start_dev`，打开前端 `http://127.0.0.1:5173/`。后端默认 `18768`。

```bash
python -m pytest -q
node --test tests/frontend_*.test.cjs
npm ci
npm run check:contracts
```
